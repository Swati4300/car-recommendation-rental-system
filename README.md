# 🚗 Car Recommendation & Rental System

A full-stack Car Recommendation & Rental System built using Flask, MySQL, HTML, CSS, and JavaScript.

## Features
- Car Recommendations
- Compare Cars
- Car Rentals
- Wishlist
- Admin Dashboard
- User Authentication

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask

### Database
- MySQL

## Installation

```bash
pip install -r requirements.txt
python app.py
```
